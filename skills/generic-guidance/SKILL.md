# Generic engineering guidance

Apply when creating, adapting or maintaining reusable skills for future projects.
Write complete generic instructions, decisions, examples and acceptance criteria.
Do not name prior application repositories, map lessons to their files/revisions,
or require their checkout to understand or execute a procedure.

Read the [procedure](references/procedure.md). Link required tools and templates
within the adopted knowledge bundle. Official API/OS/standards references remain
valid evidence, subject to [freshness checks](../knowledge-freshness/SKILL.md).
Actual copied/adapted code, assets or text follows
[third-party-reuse](../third-party-reuse/SKILL.md); removing a lesson map never
removes required attribution or changes ownership.
